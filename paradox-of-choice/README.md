# פרדוקס הבחירה — The Paradox of Choice

מצגת אנימטיבית בעברית, 10 שקפים, 1920×1080 (16:9).
בנויה ב־React + GSAP + SVG + CSS. כל הספריות והפונטים נמצאים בתיקייה, **אין צורך באינטרנט ואין צורך בהתקנה**.

## הפעלה

**הדרך הפשוטה:** לחיצה כפולה על `index.html` (מומלץ לפתוח ב־Google Chrome).

**דרך חלופית (שרת מקומי):** אם הדפדפן חוסם קבצים מקומיים, פותחים Terminal בתיקייה ומריצים:

```bash
python3 -m http.server 8000
```

ואז גולשים אל `http://localhost:8000`.

## לפני השיעור

1. פותחים את `index.html` ולוחצים **F** למסך מלא.
2. (אופציונלי) לוחצים **P** — נפתח חלון מציג עם הערות הדובר, טיימר ומונה לחיצות. גוררים אותו למסך של המחשב הנייד, ואת המצגת למקרן.
3. המצגת נפתחת **במצב המתנה** — אנימציית הפתיחה מתחילה רק בלחיצה הראשונה על רווח, בדיוק כשאתם מוכנים.

## שליטה

| מקש | פעולה |
|---|---|
| רווח / חץ ימינה / חץ למטה / PageDown | הבא (או השלב הבא בתוך השקף) |
| חץ שמאלה / חץ למעלה / PageUp | שקף קודם (מוצג במצב הסופי שלו) |
| R | הפעלה מחדש של האנימציה בשקף הנוכחי |
| F | מסך מלא |
| P | חלון מציג עם הערות |
| 1–9, 0 | קפיצה לשקף 1–10 |
| H | עזרה |

- לחיצות בזמן אנימציה או מעבר נבלעות — אי אפשר "לשבור" מעבר בלחיצות מהירות.
- המקשים עובדים גם כשהמקלדת על עברית.
- שלט מצגות (clicker) עובד — הוא שולח PageDown/PageUp.
- לחזרות: `index.html?s=6` פותח ישר את שקף 6 במצב הסופי.

### שלבים פנימיים (לחיצות בתוך שקף)
- **שקף 5** — 3 לחיצות: התלבטות → עומס מחשבתי → חרטה
- **שקף 6** — לחיצה אחת: "לפני" מתארגן ל"אחרי"
- **שקף 7** — 3 לחיצות: היררכיה → קבוצות → חשיפה הדרגתית
- **שקף 8** — לחיצה אחת: הכאוס הופך לפוסטר ו"לא בהכרח." מופיע

## הערות דובר
- `notes.html` — מסמך הערות מלא להדפסה / קריאה.
- או חלון המציג (מקש **P**).

## מבנה הפרויקט
```
index.html            נקודת כניסה
notes.html            הערות דובר (להדפסה)
src/lib.js            מערכת העיצוב: רכיבי טיפוגרפיה, צורות, עקומות תנועה, hook לשקף
src/transitions.js    מעברי מסך מלא (panels, stack, pill, iris, grid, diagonal, blinds)
src/slides/s01–s10    כל שקף הוא רכיב React עם timeline משלו
src/notes.js          טקסט הערות הדובר
src/app.js            מנוע המצגת, מקלדת, מונה, חלון מציג
src/styles.css        טוקנים וסגנונות
vendor/  fonts/       React, htm, GSAP, ופונטים (Heebo, Frank Ruhl Libre, IBM Plex Mono) מקומיים
```
